The WordPress plugin is part of **Viglet Turing**, and so is the page that lists each of its
features, the block that shows it and which ones need a language model:
[Viglet Turing for WordPress: features](https://turing.viglet.org/docs/integrations/wordpress/features/).
For installing and configuring the plugin, start at
[Viglet Turing for WordPress](https://turing.viglet.org/docs/integrations/wordpress/).
