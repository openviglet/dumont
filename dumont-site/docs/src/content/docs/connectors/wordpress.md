---
title: "WordPress: part of Viglet Turing"
description: The WordPress and WooCommerce plugin is part of Viglet Turing, not a Viglet Dumont connector. Its documentation lives on turing.viglet.org.
---

The WordPress and WooCommerce plugin, **Viglet Turing Search** (`viglet-turing-search`), is part
of **Viglet Turing**. It runs inside WordPress and sends content straight to Viglet Turing, so
it never goes through Viglet Dumont and needs no Viglet Dumont install.

Install it, configure it and try the demo store from its documentation:
[Viglet Turing for WordPress](https://turing.viglet.org/docs/integrations/wordpress/).
The product page is [Viglet Turing for WordPress and WooCommerce](https://turing.viglet.org/wordpress/),
and the demo store runs at [turing.viglet.org/wp-demo/](https://turing.viglet.org/wp-demo/).

This page stays at its old address so links to it keep working. For sources Viglet Dumont
does read, see the [connectors overview](/docs/connectors/overview/).
